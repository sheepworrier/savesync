Privacy Policy

SaveSync · Last updated 15 November 2026

SaveSync is a personal tool used only by its owner to back up game save files to their own Google Drive.

Data accessed

With the owner's permission, SaveSync accesses the owner's Google Drive solely to read, create and update game save files in a dedicated folder (GameSaves). It does not read, use or modify any other files.

How data is used and stored

Save files are copied only between the owner's own devices and the owner's own Google Drive. SaveSync has no server. The OAuth access token is stored only on the owner's devices, in the rclone configuration file.

Sharing

No data is collected, sold, shared with or transferred to any third party. No analytics, advertising or tracking are used.

Google API Services

SaveSync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from myaccount.google.com/permissions. Deleting the rclone configuration on a device removes the stored token from that device.
