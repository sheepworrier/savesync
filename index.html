SaveSync

A personal game-save backup tool

SaveSync is a small personal script that backs up game save files to the owner's own Google Drive and restores them between the owner's own devices (a Chromebook and an Android phone).

It is used by its owner only. It is not offered to the public and has no other users.

What it does

  • Before a game session, it downloads any save files on Google Drive that are newer than the local copy.
  • After a game session, it uploads the local save files to a folder in the owner's Google Drive.
  • It keeps older versions in a history folder on the same Drive so a corrupted save can be restored.
